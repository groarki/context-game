# How to run

A React Native project built with Expo.

## Requirements

- [Node.js](https://nodejs.org/) (LTS)
- The **Expo Go** app on your phone, or an Android emulator / iOS simulator

## Getting started

```bash
npm install
npx expo start
```

Then scan the QR code shown in the terminal with Expo Go,
or press `a` to open the Android emulator or `i` to open the iOS simulator.
